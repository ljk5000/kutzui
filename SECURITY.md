# Security

## Supported versions

The current download on the [Releases](https://github.com/ljk5000/kutzui/releases) page is the
supported version. Older tags are not maintained.

## Reporting a vulnerability

Please report a security issue privately, through GitHub private vulnerability reporting:

<https://github.com/ljk5000/kutzui/security/advisories/new>

Include the addon version from `KutzUI/KutzUI.toc`, what you observed, and enough detail to
reproduce it. Do not open a public issue for a security problem, and do not post exploit details
in discussions.

There is no bug bounty. You will get a reply when the report is seen.

The addon does not open its own network connections. Reports about saved variables, the profile
importer, or text the addon monitor stores are in scope. A crash or a visual bug can be a normal
[issue](https://github.com/ljk5000/kutzui/issues).
