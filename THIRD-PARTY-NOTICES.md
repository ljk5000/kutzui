`tools/make_textures.py`. They are original and under this project's MIT licence.

## Used at run time, not shipped

- **World of Warcraft** interface code and art are Blizzard's. The addons call the game's API and use
  its built-in textures by path. None of Blizzard's files are copied; `KutzUI/UIFontList.lua` lists
  the *names* of the game's font objects.
- **LibSharedMedia-3.0**: if another addon loads it, KutzUI reads its texture list. Not bundled.
