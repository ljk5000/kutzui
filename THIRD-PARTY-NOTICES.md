The fonts are unmodified and keep their names (the OFL requires that, because Anonymous Pro has a
Reserved Font Name). Each licence file ships beside its font in every zip.

The Lucide atlas contains only the icons used by KutzUI. Unmodified SVG sources and the pinned upstream
revision are in `tools/lucide/`; `tools/make_lucide_icons.js` renders the tintable atlas and shared Lua
helper. The full upstream licence, including the Feather notice, ships beside the atlas. Lucide:
<https://lucide.dev/>; source: <https://github.com/lucide-icons/lucide>.

The cast bar textures and corner masks in `KutzUI/Media/Textures` are generated by
`tools/make_textures.py`. They are original and under this project's MIT licence.

## Used at run time, not shipped

- **World of Warcraft** interface code and art are Blizzard's. The addons call the game's API and use
  its built-in textures by path. None of Blizzard's files are copied; `KutzUI/UIFontList.lua` lists
  the *names* of the game's font objects.
- **LibSharedMedia-3.0**: if another addon loads it, KutzUI reads its texture list. Not bundled.

## Development tools (not in any download)

Installed by `npm ci` in `tools/` from `tools/package-lock.json`: fengari (MIT) and luaparse (MIT).
Optional, not in the repository: taintlint (MIT), cloned separately for the secret-value lint.
Icon regeneration optionally uses `@resvg/resvg-js` 2.6.2 (MPL-2.0), installed separately outside the
repository. It is a build tool only and is not bundled with the addon.

## Ideas, not code

Some comments name other addons whose *behaviour* was studied: EllesmereUI (all rights reserved), for
which Blizzard calls taint the chat frames, and Details!, for the look of the combat log window. No
code from either was copied.
